# TechHub Computer Center Website

> A modern, responsive educational portal and landing page for a computer training institute offering certified courses in programming, data analytics, design, and cybersecurity.

---

## Features

- **Educational Hero Showcase**: Visually compelling hero banner with enrollment calls-to-action and student trust metrics.
- **Mission & Institutional Vision**: Highlights practical career-oriented training, hands-on lab sessions, and personalized mentorship.
- **Interactive Course Catalog**:
  - Detailed course cards with curriculum breakdowns, prerequisites, and syllabi.
  - Course metadata badges including duration (e.g., 2–3 months) and skill level (Beginner to Intermediate).
  - Programs featured: Full Stack Web Development, Data Analysis with Python, Graphic Design & UI/UX, and Cybersecurity.
- **Dynamic Swiper Carousel**: Embedded touch-friendly Swiper slider for displaying featured programs and student testimonials.
- **Scroll-Triggered Animations**: Smooth reveal animations powered by AOS (Animate on Scroll) and Animate.css.
- **Student Enrollment & Inquiry Form**: Contact and registration section for scheduling consultations and reserving seats.
- **Mobile Responsive Layout**: Built with Bootstrap 5 grid utilities and custom responsive CSS rules.

---

## Tech Stack

- **Markup**: HTML5 (semantic layout and accessible structure)
- **Styling**: CSS3 (custom theme color variables, CSS Grid, Flexbox, custom course cards)
- **Frameworks & Libraries**:
  - [Bootstrap 5.3.2](https://getbootstrap.com/) (responsive grid, layout containers, and navbar)
  - [Swiper 11](https://swiperjs.com/) (touch slider / carousel)
  - [AOS 2.3.1](https://michalsnik.github.io/aos/) (scroll animations)
  - [Animate.css](https://animate.style/) (CSS entrance effects)
  - [FontAwesome 6.4.0](https://fontawesome.com/) (course, clock, and UI icons)
- **Typography**: Google Fonts ([Poppins](https://fonts.google.com/specimen/Poppins))

## How to Install and Run

This project runs directly in any modern browser without requiring dependencies to be installed.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jatin2267/Computer-Education-Center-website.git
   cd Computer-Education-Center-website
   ```

2. **Open in browser:**
   - Double-click `index.html` to open the website in your browser.
   - Or start a local development server:
     ```bash
     npx serve .
     ```
   - Open `http://localhost:3000` in your browser.
